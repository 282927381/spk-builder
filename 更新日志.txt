更新日志
V1.0.1

【新增功能】

批量处理
- 新增「📦 批量」页签：一次多选本地 .spk 文件或每行填一个本地路径，批量解包；每个包生成一张独立可编辑卡片。
- 批量修改单一信息：卡片上方「⚡ 批量修改」工具条，选字段填一次值即可同步到所有包（架构、运行身份为选择型控件）。
- 批量构建：新增 /api/batch-build 接口，逐个打包，单个失败不影响其他包，结束后汇总成功/失败。
- 批量下载：结果区每个 .spk 可勾选，顶部「全选 + 批量下载」一键下载，按镜像站(sspks-imnks)支持的架构自动默认勾选（x86_64/arm64/noarch 默认勾选，armv7 默认不勾选）；勾选的包自动打包成 zip，按 <软件名>-dsm7 文件夹分类存放。

机型命名与分发
- 构建时 INFO 的 arch 字段自动写入该架构家族的全部机型代号（家族代号在前 + 具体机型代号），群晖套件中心按机型精确匹配。
- arm64 同时写 armv8/arm64/aarch64，适配 sspks-imnks 的 armv8 家族（此前只写 arm64 会导致 ARM 机型匹配不到）。
- 修正解包反向映射 map_arch，补充新机型代号（geminilakenk/v1000nk/r1000nk/epyc7003/icelaked 等），armada37xx 归入 arm64。

顶部菜单「📜 更新日志」页签
- 内容自动读取本文件（更新日志.txt），改文件即同步更新，无需改代码。

解包二次打包保留「打开」按钮
- 自动保留 adminport/adminprotocol/adminurl/dsmuidir/dsmappname 等 Web 端口 / DSM UI 字段，带 Web UI 的套件重打包后套件中心仍显示「打开」按钮。

解包 / 批量解包日志
- 解包改为后台任务 + 实时轮询日志（新增 /api/import-job 接口），逐行实时滚动展示解包过程（提取 INFO / package.tgz / 外层文件、目标文件数、套件信息、运行身份等）。
- 批量解包时同样实时输出每个包的日志，实时查看解包进度。

【更改】
- 产物命名格式由 <名称>[-架构]-<版本>.spk 改为 <名称>_<架构>-<版本>.spk（SynoCommunity 标准，noarch 也带 _noarch 后缀）。

【修复】
- Windows 长路径（MAX_PATH）修复：新增 _long_path()、rmtree()，打包/解包/清理目录改用长路径，避免超长文件名导致 [Errno 2] 报错。
